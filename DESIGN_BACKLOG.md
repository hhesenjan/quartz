| Priority | Follow-up | Reason and trigger |
| --- | --- | --- |
| Editorial, per article | Review image alternatives when revising image-heavy tutorials. | Some Markdown screenshots have an empty alternative and nearby step instructions. An author familiar with each image should decide whether the surrounding text conveys the whole instruction. Preserve the original articles in this design change. |
| Validation, next release | Exercise search and graph-dialog controls with VoiceOver/Safari and NVDA/Firefox, and on physical touch devices. | Chromium and Firefox keyboard tests cover rendered semantics, focus and input handling. Search opened after graph teardown throughout the foreground checks. Revisit the shortcut during an operating-system motion preference change if readers report a failure. They do not measure every screen reader’s speech output. |
| Performance, when field data exists | Check Web Vitals and graph performance on readers’ devices. | The documented transfer sizes, layout shifts and paint times are from controlled local runs. CDN availability, hardware and real network latency affect field results. |
| Editorial and image pipeline, when updating asset handling | Supply intrinsic dimensions for existing Markdown image embeds that lack them. | The five IACS diagrams now reserve their exact space. A separate corpus inventory found 378 other local article image occurrences without numeric width and height. In a cold-load test the focused footer moved by 325px after the final unsized image acquired its dimensions. A stylesheet cannot reserve an unknown aspect ratio. A shared emitter change would need its own compatibility and asset-metadata review. |
| Maintenance, dependency update | Recheck the existing micromorph declaration export and remark-parse/lib type import when the dependencies change. | The untouched checkout and the design branch report the same two TypeScript errors. The production build and unit tests run independently of these errors. |
| Conditional, font coverage | Extend the OFL webfont subsets if the publication begins carrying substantial content in a new script. | System fallback currently supplies glyphs outside the local Latin subsets. Request and measure additional assets only for actual content. |
| Upstream, graph plugin | Revisit the local renderer when the graph plugin supports cancelling asynchronous initialization and disposing one Pixi application independently. Also check for reduced-motion support and separate graph-edge theme inputs. | These would let the blog remove corresponding local behavior. Preserve keyboard access, SPA cleanup and reduced-motion startup when upgrading. |
| Search, inline markup | Improve text-range matching when a search phrase starts or ends inside inline code. | In the WinGet callout, Quartz scrolls to the panel for “WinGet with --all” but creates no highlight. A reader can open the callout with the keyboard or pointer. Both the original and corrected builds showed this Search behavior. [Matched trials](design-evidence/callout-review/corrected/inline-search.json) |
| Performance, graph lifecycle | Dispose the local canvas when the tablet article rail or desktop reader mode hides it, then restore it on a visible desktop rail. Preserve the visible tablet Home graph. | With software WebGL, the hidden graph delivered 67 drawing callbacks and 134 Pixi ticker callbacks in 1.1s. CSS display suppression left both counts unchanged. The reduced-motion lifecycle removed both. This requires renderer lifecycle work. |
| Accessibility, diagram integration | Name the expanded Mermaid dialog, contain keyboard focus, support an in-dialog close action, and restore the opener. Raw source now wraps when the CDN is unavailable. | These behaviors originate in the diagram component. Baseline and final builds reproduced the underlying keyboard issues. |
| Editorial, embedded media | Give the two authored SVG objects meaningful accessible names and review the single video for a transcript or captions. | Object labels and fallback text are empty. The video has no authored text track. |
| Maintenance, clipboard plugin | Make clipboard initialization idempotent on repeated page renders. | The CSS preserves the original visible keyboard target and its focus while Quartz prepends additional hidden buttons. The plugin still creates DOM nodes and listeners. Check a numbered block and Mermaid source, including Back/Forward and resizing, when updating the plugin. |
